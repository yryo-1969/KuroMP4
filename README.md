# KuroMP4（MP4背景動画プラグイン）

MikuMikuDance の背景動画（「背景AVI」）に、`.mp4` などの動画を**変換なしでそのまま**使えるようにする MMDPlugin 用プラグインです。

MMD の背景動画は本来 `.avi` しか読み込めません。そのため、これまでは MP4 を AVI に変換する必要がありました。長い動画を変換すると、ファイルが大きくなりすぎて途中で止まったり、画質を落とす必要があったりします。KuroMP4 を入れると、MP4 を MMD の画面にドラッグ＆ドロップするだけで、元の画質のまま背景に表示できます。

- 変換・待ち時間なし。元の動画の画質のまま
- 再生、フレーム移動、AVI出力でも背景が正しく映ります
- 背景にMP4を入れたまま `.pmm` を保存して、開き直しても背景が戻ります

対応している形式: `.mp4` `.m4v` `.mov` `.mkv` `.webm` `.wmv`
（Windows に入っているデコーダーで読み込みます。H.264 の MP4 はそのまま読めます。HEVC(H.265)・VP9・AV1 などは、Microsoft Store の拡張機能が入っていないと読めない場合があります）

## 動作環境

- Windows 10 / 11（64bit）
- MikuMikuDance 9.32 x64（作者の環境で動作確認）
- MMDPlugin（oigami 様作）が導入済みであること（MME を MMDPlugin 経由で使っている環境ならそのままでOKです）

## ダウンロードと導入

1. [Releases](../../releases) から `KuroMP4_v1.0.0.zip` をダウンロードして展開します。
2. MMD のフォルダの中の `plugin` フォルダに、`KuroMP4` フォルダごと入れます。
   ```
   MikuMikuDance_v932x64\
     MikuMikuDance.exe
     MMDPlugin.dll
     d3d9.dll
     plugin\
       KuroMP4\
         KuroMP4.dll   ← これ
   ```
3. MMD を起動し直します（起動中のMMDには反映されません）。

## 使い方

- **MP4 ファイルを MMD の画面にドラッグ＆ドロップ**するだけです。背景動画として読み込まれます。
- 表示のオン・オフは、いつもどおり「背景(B)」メニューの「背景AVI表示」で切り替えられます。
- 音声は読み込まれません。音を合わせたいときは、今までどおり `.wav` を「音声の読み込み」で別に読み込んでください。

## 注意事項

- 「背景AVIファイル読込」のファイル選択画面には、MP4 が表示されません。ドラッグ＆ドロップで読み込んでください。
- MP4 を背景にした `.pmm` は、背景のパスが `動画名.mp4.avi` という名前で保存されます。開き直すときは KuroMP4 が入った MMD で開いてください。KuroMP4 が入っていない MMD で開くと、背景だけ読み込めません（モデルやモーションは普通に読み込まれます）。
- 前後に少しずつ動かすのはすぐですが、離れたフレームへ一気に移動すると、表示まで1秒くらいかかることがあります（動画の圧縮の仕組み上の都合です）。
- プラグインのフォルダに `KuroMP4.log`（動作ログ）ができます。MMD を起動するたびに中身がリセットされます。

## しくみ（開発者向け）

MikuMikuDance.exe が使う AVIFile API（`AVIFileOpenW` / `AVIStreamGetFrame` など）をインポートテーブルで横取りします。動画ファイルのときだけ Media Foundation（`IMFSourceReader`）でデコードして、AVI のふりをして1枚ずつ MMD に渡します。ふつうの AVI はそのまま本来の処理に流します。

ドラッグ＆ドロップのときは、`DragQueryFile` で `x.mp4` を `x.mp4.avi` に見せて、MMD に背景AVIとして扱わせます。そのあと、ファイルの存在確認（`_wsopen_s` など）や読み込みのときに、本物の `x.mp4` へつなぎ直します。

### ビルド

Visual Studio 2022 Build Tools（C++）が必要です。

```
build.bat
```

`KuroMP4.dll` ができます（`/MT` 静的リンクなので、ランタイムの追加インストールは不要です）。
